# Scope

LLM Index covers **text models that are available through Venice, Morpheus, or both**.

The site exists to rank those provider catalogs and provide enough sourced context for users to understand model tradeoffs.

Out of scope for the primary product surface:

- general-purpose all-provider model discovery;
- multimodal-only leaderboards;
- a separate documentation website;
- editorial model reviews;
- unlabeled synthetic scores from unrelated model populations.
