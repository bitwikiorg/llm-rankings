# Ranking Sources

| Source | Role in LLM Index | Native display |
| --- | --- | --- |
| Arena | Overall capability signal | rank, score, votes where available |
| Artificial Analysis | Overall/reasoning capability signal | Intelligence Index and published rank where available |
| LLM Stats | Overall + reasoning/coding/agent signals | native score and published rank where available |
| Kilo | Coding signal | completion/cost evidence |
| Venice | model availability + provider pricing | provider-native metadata |
| Morpheus | model availability + provider pricing | provider-native metadata |
| Official/model cards | technical metadata and release provenance | direct reference |

External leaderboard positions are never treated as interchangeable rank numbers. The public site rank is derived from normalized measurements on the tracked model set.
